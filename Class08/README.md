# Spider-Verse: Registro de Héroes (Class08)

Aplicación interactiva de reclutamiento multiversal desarrollada con HTML5, CSS3 y TypeScript. Implementa gestión dinámica del DOM, delegación de eventos, validaciones de negocio, filtrado, ordenamiento y persistencia de datos.

## Obtener el proyecto

Clonar el repositorio:
```bash
git clone https://github.com/YonaZakkart/event-oriented-programming.git
```

O descargar el ZIP desde GitHub (botón "Code" → "Download ZIP") y descomprimir en una carpeta local.

## Instalación

Navega a la carpeta de la Clase 
```bash
cd Class08
```

Dentro de la carpeta del proyecto (Class08):
```bash
npm install
```

## Ejecución

Compilar TypeScript en modo escucha (Watch)
```bash
npx tsc script.ts -w --ignoreConfig
```

## Abrir en el navegador

Abre el archivo index.html directamente en tu navegador o utiliza la extensión de servidor local Live Server

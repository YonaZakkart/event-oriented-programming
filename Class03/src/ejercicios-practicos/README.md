# Sesión 3 — Fundamentos de TypeScript
Ejercicios practicos de repaso de TypeScript: Programación Orientada a Eventos (POE).

## Requisitos

- Node.js instalado

## Instalación

```bash
npm install
```

## Ejecución

### Opción A — Compilar con TypeScript

```bash
npx tsc
node dist/nombreArchivo.js
```
ejemplo: "node dist/ejercicio1.js"

### Opción B — Ejecutar directo con tsx

*Requiere tsx instalado globalmente:*
```bash
npm install -g tsx
```

Ejecutar con tsx
```bash
npx tsx nombreArchivo.ts
```
ejemplo: "npx tsx ejercicio1.ts"
